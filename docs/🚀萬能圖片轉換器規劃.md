# 🚀 萬能圖片轉換器 (Universal Image Converter) 技術開發指南

本文件定義了 ClawStudio 萬能圖片轉換 API 的核心架構、技術選型與關鍵實作邏輯。

## 一、 核心轉換功能矩陣

| 功能模組 | 轉換組合 | 核心技術 (Library) | 實現方式與重點 |
| :--- | :--- | :--- | :--- |
| **網頁優化** | PNG / JPG ↔ WebP | `sharp` | 支援有損/無損壓縮，WebP 轉 PNG 需保留 Alpha 通道。 |
| **向量轉點陣** | SVG ↔ PNG | `sharp` + `librsvg` | 底層依賴 `librsvg` 渲染，需處理字體缺失 (Font Fallback) 問題。 |
| **開發者工具** | PNG ↔ ICO | `sharp` + `png-to-ico` | 需先 Resizer 產出多尺寸 Buffer，再封裝進 ICO 容器。 |
| **Apple 格式** | HEIC ↔ JPG/PNG | `sharp` + `libheif` | 需在 Docker 環境編譯 `libvips` 以支援 HEIF 解碼。 |
| **通用互轉** | JPG ↔ PNG | `sharp` | PNG 轉 JPG 需使用 `.flatten()` 填充透明背景。 |

---

## 二、 後端技術棧 (Technology Stack)

* **Runtime**: Node.js (建議版本 18-bullseye 或 20)
* **Engine**: `sharp` (高性價比的 C++ 影像處理庫)
* **Infrastructure**: Google Cloud Run (無狀態容器化部署)
* **API Framework**: Express.js 或 Fastify
* **File Handling**: `multer` (處理 Multipart/form-data)

---

## 三、 SVG 渲染字體解決方案

針對 SVG 轉 PNG 出現的「字體跑版」或「方塊字」問題，採用以下策略：

### 1. 容器環境預裝 (Dockerfile 實作)
在 Cloud Run 容器中預裝開源字體包，解決 80% 的繁簡中、日、韓、英文字體需求。
```dockerfile
# Dockerfile 片段
RUN apt-get update && apt-get install -y \
    fonts-noto-cjk \
    fonts-noto-color-emoji \
    fonts-liberation \
    fonts-dejavu && \
    fc-cache -f -v
```

### 2. 應用層優化建議
* **Base64 內嵌**: 建議使用者在 SVG 內使用 `@font-face` 並將字體轉為 Base64 字串。
* **文字轉路徑**: 引導專業開發者將 SVG 文字轉為 `path` (Outline)，可達 100% 渲染還原度。
* **CSS fallback**: 在 API 邏輯中強制注入 `font-family: "Noto Sans CJK TC", sans-serif;` 作為後備方案。

## 四、 核心實作範例 (Node.js + Sharp)

### 1. 通用轉換函式
```javascript
const sharp = require('sharp');

async function convertImage(inputBuffer, targetFormat, options = {}) {
  let pipeline = sharp(inputBuffer);

  // 處理透明背景填充 (PNG -> JPG)
  if (targetFormat === 'jpg' || targetFormat === 'jpeg') {
    pipeline = pipeline.flatten({ background: { r: 255, g: 255, b: 255 } });
  }

  // 設定格式與質量
  return await pipeline
    .toFormat(targetFormat, {
      quality: options.quality || 80,
      lossless: options.lossless || false
    })
    .toBuffer();
}
```

### 2. HEIC 轉 PNG 範例
```javascript
// 需確保 Sharp 已編譯 libheif 支援
const pngBuffer = await sharp(heicBuffer)
  .toFormat('png')
  .toBuffer();
```

## 五、 後續擴展建議 (Roadmap)

1.  **批次處理 (Batch Processing)**: 支援上傳多張圖片並打包成一個 `.zip` 下載。
2.  **MCP 整合**: 開發 Model Context Protocol 插件，讓 AI Agent 能直接調用此 API 進行素材加工。
3.  **ComfyUI Node**: 製作 Custom Node，將圖片處理邏輯外包 (Offload) 給此 API，節省本地顯存。

---

> **💡 提示**: 
> 當你在 Cloud Run 部署時，請確保配置 **1GB 以上的 RAM**。`sharp` 在處理高解析度 SVG 或 HEIC 轉檔時會瞬間消耗大量記憶體。
